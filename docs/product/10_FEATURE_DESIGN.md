## V1 增强功能（基于推荐产品，1-2 周可加）

### 🌟 增强 1：影子跟读（Shadowing）

**用到的产品**：豆包语音合成2.0 + 一句话识别-教育中文

**功能**：
```
1. AI 用自然语音读一句话（TTS 播放）
2. 用户立刻跟读（录音）
3. ASR 转录用户发音
4. 对比原文：
   - 发音准确度
   - 语速匹配度
   - 停顿位置
5. 评分 + 逐字对比
```

**场景示例**：
```
AI 老师读：今天天气真不错，我们去公园走走吧。
你跟读：今天天气真不错，我们去公园走走吧。
评分：
  今天 ✅  天气 ✅  真不错 ⚠️（"真"第四声读成第一声）
  我们 ✅  去公园 ✅  走走吧 ❌（少了一个"走"字）
```

**为什么好**：
- 影子跟读是语言学界公认的口语训练最佳方法
- 用户不需要"想要说什么"，专注于发音模仿
- 适合所有 HSK 级别

**数据来源**：
- HSK 1-6 教材经典句子
- 日常生活常用句
- 新闻头条句子（HSK 5-6）

### 🌟 增强 2：多音色 AI 老师

**用到的产品**：豆包语音合成2.0（8 种音色）

**功能**：
```
设置页 → AI 老师音色选择：
  🔴 灿灿（女，亲切自然）— 默认
  🔵 擎苍（男，沉稳磁性）
  🟡 棉米（女，软萌甜）
  🟢 奶绿（女，温柔知性）
  🟣 超人（男，活力标准）
  ...
```

**为什么好**：
- 不同用户偏好不同的声音
- 听不同口音/音色提高听力适应力
- 实现成本极低（改 1 个 voice_type 参数）

**实现工作量**：半天（设置页加选择器 + TTS 调用传 voice_type）

### 🌟 增强 3：HSK 词汇发音训练

**用到的产品**：豆包语音合成2.0 + 一句话识别-教育中文

**功能**：
```
1. 选 HSK 等级 + 选词库（如"HSK 3 动物词"）
2. AI 读一个词 + 显示拼音
3. 用户跟读
4. AI 评分（声调准确度）
5. 错误的词自动进入错题本 SRS
```

**为什么好**：
- 精准攻克声调问题（中文学习最大痛点）
- 声调训练 = ChatMandarin 核心差异化
- 碎片化学习（每次 3 分钟）

## V2 创新功能（需要额外产品，1-3 月）

### 🎬 创新 1：经典影视配音（Killer Feature）

**用到的产品**：
- **精品长文本语音合成-情感预测版**（AI 带感情地读对白）
- **音视频字幕生成**（提取电影对白文本）
- **一句话识别-教育-中文**（识别用户配音）

**功能流程**：
```
1. 选经典片段（如《你好，李焕英》《流浪地球》《长安三万里》）
2. 看视频片段（30 秒 - 1 分钟）
3. 显示中文字幕 + 拼音
4. AI 先用情感 TTS 示范对白（让用户听到标准发音 + 情感）
5. 用户配音（关闭原声，读出字幕）
6. AI 评分：
   - 发音准确度
   - 情感匹配度（是否像角色一样开心/生气/悲伤）
   - 时序同步（是否跟上节奏）
7. 可对比"你的版本"vs"AI 示范"
```

**为什么是杀手级功能**：
- **用户粘性极强**（看电影学中文是很多学习者的梦想）
- **情感学习**（中文不是只有发音，还有语气）
- **社交传播**（用户可以分享自己的配音）
- **差异化**（HelloChinese/Speak 都没有这个）

**版权处理**：
- 不直接嵌入电影视频
- 只用"文本对白"（公开的剧本/字幕）
- AI 生成情感语音替代原声
- 用户自带视频或用公开素材

**预估开发**：3-4 周

### 🎭 创新 2：AI 角色扮演（沉浸式对话）

**用到的产品**：
- **豆包语音合成2.0**（不同角色用不同音色）
- **声音复刻大模型**（克隆特定角色声音，V3）

**功能流程**：
```
选择角色：
  🧓 老北京大爷 → 聊胡同、老字号、传统文化
  👩‍💼 上海白领 → 聊职场、加班、买房
  🧑‍🎨 成都年轻人 → 聊美食、生活节奏
  👨‍🏫 严格语文老师 → 纠正每一个错误
  🧕 新疆大妈 → 聊丝绸之路、美食

每个角色：
- 独特音色（TTS voice_type）
- 独特人设（DeepSeek persona prompt）
- 独特词汇（地域特色 + 语气词）
```

**为什么好**：
- 比通用场景更有趣
- 接触真实多样的中文（不只是"标准普通话"）
- 每个角色有独特人格 → 对话更有深度

**预估开发**：1-2 周（主要是角色数据 + prompt）

### 📝 创新 3：语音日记（每日中文表达）

**用到的产品**：
- **一句话识别-教育-中文**
- **豆包语音妙记模型**（自动提取关键词/摘要）

**功能流程**：
```
每天一个主题：
  周一：今天发生了什么有趣的事？
  周二：你最喜欢的中国菜是什么？为什么？
  周三：描述你的一位朋友
  ...

用户用中文说 1-2 分钟
  ↓
ASR 转录
  ↓
AI 分析：
  - 语法纠正
  - 用词建议
  - 词汇丰富度评估
  - 提取用户"新学的词"
  ↓
生成"学习日记"（带 AI 点评）
  ↓
时间线：30 天后看到自己的进步
```

**为什么好**：
- 自由输出（不像对话有固定方向）
- 情感连接（记录自己的故事）
- 长期留存（不想断更"日记"）

**预估开发**：1-2 周

### 🎵 创新 4：中文歌曲学唱

**用到的产品**：豆包语音合成2.0 + 一句话识别

**功能流程**：
```
选歌曲（经典中文歌 + 网络流行）：
  《月亮代表我的心》《甜蜜蜜》《青花瓷》《孤勇者》

1. 显示歌词（中文 + 拼音 + 翻译）
2. AI 用 TTS 逐句"念"歌词（慢速）
3. 用户跟读
4. 逐句评分（发音 + 声调）
5. 挑战模式：跟着原曲节奏唱（ASR 识别）
```

**为什么好**：
- 学中文歌是全球中文学习者的刚需
- 音乐 + 语言 = 超强记忆
- 社交传播（唱中文歌发 TikTok）

**版权处理**：
- 只提供歌词文本 + AI 生成的念白（不用原曲音频）
- 用户自己找原曲伴奏

---

### 🌐 创新 5：实时翻译模式（高级学习者）

**用到的产品**：豆包同声传译2.0

**功能流程**：
```
用户说英语 → 实时翻译成中文（文字 + 语音）
用户尝试用中文重复 → AI 检查发音和语法
对比"AI 翻译版本"vs"用户中文版本"
```

**为什么好**：
- 适合 HSK 4+ 高级学习者
- 训练"思维转换"能力（英语思维→中文思维）
- 比单纯对话更有挑战性

---

### 🗣️ 创新 6：方言体验馆

**用到的产品**：
- **一句话识别-通用-粤语**
- **一句话识别-通用-川渝**
- **豆包语音合成2.0**

**功能流程**：
```
选方言：
  🇭🇰 粤语 → 听经典粤语对白 + 学几句
  🌶️ 四川话 → 听川渝方言 + 趣味表达

AI 用方言 + 普通话对比朗读
用户尝试模仿
ASR（方言模型）识别评分
```

**为什么好**：
- 很多学习者对中国方言感兴趣
- 了解语言多样性
- 趣味性极强
