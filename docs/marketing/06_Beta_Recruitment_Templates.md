## 渠道 2：Reddit r/ChineseLanguage 招募

**⚠️ 重要**：r/ChineseLanguage Rule 3 严禁自荐，**没有"周末例外"**。
任何带产品名 / 链接 / "I'm building X" 的帖都会被删，账号可能 ban。
必须**先 modmail 申请预审**，等 mod 明确批准后才能发。
不要绕规则、不要换标题重发，会被认为是 evasion。

**操作流程**：
1. 先在 r/ChineseLanguage 真实参与 2-3 周（评论、答题、问问题），累积 50+ karma
2. 给 mods 发 modmail 申请："I'd like to share a beta recruitment post..."
3. 等 mod 明确批准后再发下面的文案
4. 在帖子里**明确标注** "Mod approved this post on [date]"

**批准后才能用的文案**：

**标题**：
```
Looking for 20 beta testers for AI Chinese tutor (HSK learners)
```


## 反馈分类处理

### P0：阻塞性 bug（24 小时内修）
- 无法登录
- 对话中断
- 付费失败

### P1：体验问题（1 周内修）
- 反馈不清晰
- 加载慢
- 移动端 bug

### P2：功能建议（V2 考虑）
- 新场景
- 新功能
- UI 优化

### P3：拒绝（不做）
- "Can you add [unrelated feature]"
- "Can you make it free"

## 风险与对策

### 风险 1：Beta 用户不足

**对策**：
- 提前 2 周开始招募
- 多渠道并行（至少 3 个）
- 个人网络全力动员

### 风险 2：用户不活跃

**对策**：
- 主动邮件跟进（3 天、7 天、14 天）
- 在 Discord @ 不活跃用户
- 提供"完成 5 局解锁额外奖励"

### 风险 3：负面反馈多

**对策**：
- 不要抵触
- 每条建议都回复
- 修复后立即通知提建议的用户
- 把"修复"作为内容输出（X 推文）
