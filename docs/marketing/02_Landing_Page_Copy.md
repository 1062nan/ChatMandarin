## FAQ Section

### 标题
```
Questions?
```

**Q: Do I need to know Chinese already?**
A: ChatMandarin supports HSK levels 1-6. Complete beginners can start with HSK 1 conversations — we'll guide you word by word.

**Q: How is this different from Duolingo?**
A: Duolingo is great for vocabulary and basic grammar. ChatMandarin is for when you want to actually speak. We focus on real conversation practice with real-time AI feedback.

**Q: Will the AI correct my tones?**
A: Yes — every sentence you speak gets tone-by-tone analysis. You'll see your tone curve vs. the correct one, with specific feedback on what to improve.

**Q: Is this useful if I'm not taking HSK?**
A: Absolutely. HSK levels map to vocabulary difficulty. If you want to practice conversation at a "I can order food and have basic chats" level, that's roughly HSK 3.

**Q: When does ChatMandarin launch?**
A: We're opening private beta in [Month, Year]. Waitlist members get in first, with 30% off the first year.

**Q: Is my data safe?**
A: We don't store your voice recordings. Conversation text is stored only so you can review your progress. You can delete everything anytime.

## Carrd 搭建具体步骤

1. 注册 Carrd.co（$19/年 Pro）
2. 选模板：使用 "Spotlight" 或 "Landing" 类
3. Sections（按顺序）：
   - Hero（主标题 + 副标题 + CTA）
   - Why（3 列痛点）
   - Features（5 个 feature blocks）
   - Trust（技术栈）
   - Compare（表格）
   - Pricing（3 个 plan blocks）
   - Founder（个人故事）
   - FAQ
   - Footer

4. 颜色方案：
   - 主色：墨黑 #1a1a1a
   - 辅色：朱砂红 #c23b22
   - 背景：米白 #f8f5f0
   - 文字：深灰 #333333

5. 字体（Carrd 自带）：
   - 标题：Inter / SF Pro Display
   - 中文：Noto Serif SC（思源宋体）
   - 正文：Inter Regular

6. 集成：
   - ConvertKit form（Waitlist 邮箱收集）
   - X 按钮（关注跳转）
   - Discord 邀请链接（W3 后加）
